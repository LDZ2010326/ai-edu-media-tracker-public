# Roadmap

Roadmap 表达方向，不是发布时间承诺。具体工作以已接受的 Issue 和 Pull Request 为准。

## 近期方向

- 提升多知、多鲸、芥末堆的日期识别、错误诊断和回归样例覆盖。
- 改进示例报告、安装验证与跨平台开发说明。
- 持续收紧抓取、证据验证、依赖与发布链路的安全门禁。

## 未来探索

- 在维持固定来源和显式信任边界的前提下，评估社区提出的新公开数据源。
- 探索结构化导出格式和不依赖特定宿主 Agent 的展示方式。
- 评估可复现的离线演示数据集，降低首次体验对网站可用性的依赖。

## 明确非目标

- 不提供绕过登录、付费墙、验证码、robots 约束或网站访问控制的能力。
- 不托管或转载文章正文，不承诺内容永久可用。
- 不内置云端账号、飞书凭证或默认自动发布行为。
- 不把网页内容当作可信指令，也不保证外部站点输出的事实正确性。
